# GenLayer Gateway

GenLayer Gateway is a testnet interchain adjudication protocol. It lets a Base Sepolia application submit a structured question, immutable policy, and versioned evidence manifest to a GenLayer Intelligent Contract. The finalized decision returns to Base and may trigger an application callback.

The product has two surfaces: a **developer gateway** for integrating reviewed GenLayer capabilities into an existing application, and a **read-only observatory** for inspecting the deployed route and its evidence. The observatory never submits transactions; the escrow implementation remains protocol test coverage, not the public product.

> **Testnet status:** version 0.1.0 is not audited and rejects non-Base-Sepolia origin deployments.

## Why it exists

Deterministic smart contracts enforce rules well, but cannot reliably interpret repositories, documents, agent output, or ambiguous evidence. Gateway separates three responsibilities:

| Layer | Responsibility |
| --- | --- |
| Origin application | Holds funds and defines consequences |
| Transport | Carries authenticated bytes |
| GenLayer | Evaluates evidence and finalizes judgment |

The API and database index the lifecycle. They never decide whether work passed.

Start with the [Integration guide](/docs/integration) if you are deciding whether to use the shared adjudicator, bring your own Intelligent Contract through a managed route, or operate an adapter yourself.

## First reference integration

The included `AgentEscrow` is a reference integration: it locks funds on Base Sepolia, receives worker evidence, asks GenLayer to verify the work, and releases or refunds after an authenticated verdict. `UNDETERMINED` enters a recoverable application state rather than guessing. Developers do not need to use this application contract; they can integrate the Gateway adapter into their own application.

## Core guarantees

- Exact `0.001 ETH` request prepayment.
- Domain-separated request IDs.
- Monotonic application nonces.
- Evidence and policy commitments.
- Authenticated result entry point.
- One-time result finalization.
- Retryable, idempotent callback delivery.
- Explicit timeout and undetermined states.

## Use the observatory

- **Explorer** at `/explorer`: search indexed request IDs, transactions, LayerZero message IDs, evidence URLs, statuses, and decisions.
- **Request inspection** at `/explorer/:requestId`: compare indexed lifecycle data with a direct read from the configured GenLayer contract.
- **Evidence** at `/evidence`: inspect deployed addresses, smoke-test results, phase-gate outcomes, and the documented fail-closed outlier.
- **Integration docs** at `/docs/integration`: learn how to use the shared route, onboard a custom Intelligent Contract, or self-host an adapter.

The write APIs and contracts remain available to programmatic developers. The public website has no wallet provider, local job store, or browser transaction workflow.
